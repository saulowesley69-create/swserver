# Blockverse

Browser-based voxel sandbox prototype built with Three.js.

## Run locally

Run `npx serve .` in this folder, then open the local URL. Three.js is loaded from jsDelivr as an ES module.

## Controls

- WASD: move
- Mouse: look
- Space: jump
- Shift: sprint
- Left click: mine
- Right click: place selected block
- 1–6: select hotbar slot
- Esc: pause and settings

## Current features

- Procedural block terrain, hills and trees
- First-person camera, gravity, jumping and basic collision
- Mining and block placement
- Six-slot hotbar and simple inventory counts
- Day/night lighting cycle
- Pause menu with mouse sensitivity and view distance

## Roadmap

Real chunk streaming, persistent saves, crafting, tools, creatures, survival systems, audio, particles and multiplayer.
