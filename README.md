# VoxelMundo (APK Android)

Branch só do app Android do VoxelMundo.

- O jogo fica em `VoxelMundo/app/src/main/assets/index.html` (o mesmo `voxelmundo.html` do site).
- A cada push neste branch, o GitHub Actions gera o APK e publica em **Releases** (`voxelmundo-vN`).
- Tela cheia: a barra de navegação e a de status do celular ficam escondidas (modo imersivo).
- O botão de voltar do celular funciona como a tecla Esc do jogo (pausa / fecha janelas).
